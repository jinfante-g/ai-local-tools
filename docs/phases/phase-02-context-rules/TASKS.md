# Phase 02 task checklist

## Before approval

- [ ] Read phase 01 outcomes, current status, project charter, architecture, and corporate requirements.
- [ ] Identify ambiguity, duplication, or conflicting instructions.
- [ ] Propose concise rule edits and affected files.
- [ ] Define a small compliance exercise and pass/fail rubric.
- [ ] Present the plan and wait for explicit Gate 1 approval.

## After approval

- [ ] Keep root AGENTS.md short and link to detailed rules.
- [ ] Make project status the source of truth for planned, pending, and implemented work.
- [ ] Ensure architecture, AI, security, testing, and documentation rules agree.
- [ ] Run the approved exercise using synthetic data and exact documented context.
- [ ] Check plan/output for approval, scope, privacy, language, and truthful test claims.
- [ ] Record prompt, output location, reviewer, results, and limitations.
- [ ] Fix rule gaps or record an approved limitation; rerun affected checks.
- [ ] Request independent audit and resolve findings.
- [ ] Update status and submit a pull request to main.
- [ ] Record owner acceptance before phase 03.
