# Phase 01 task checklist

## Before approval

- [ ] Read root agent instructions, project charter, status, and relevant rules.
- [ ] Gather applicable corporate standards and repository restrictions.
- [ ] Propose repository/toolchain setup and first Bug Briefs slice.
- [ ] Define measurable acceptance criteria, including what will count as an AI capability if proposed.
- [ ] Identify dependencies, network flows, data handled, risks, tests, and evidence.
- [ ] Present the plan and record explicit Gate 1 approval.

## After approval

- [ ] Create/use a feature branch and approved repository setup.
- [ ] Verify current stable Angular version and package compatibility.
- [ ] Verify Tailwind CSS, Angular CDK, storage, and test tooling against corporate standards.
- [ ] Define the first slice and keep unselected features out of scope.
- [ ] If including local AI, complete Gate 2 for the exact runtime and model before integration.
- [ ] Implement the approved slice with accessible UI states and clear failure handling.
- [ ] Add focused unit tests for non-trivial behavior; add E2E only where approved.
- [ ] Run and record checks; capture synthetic-data screenshots where useful.
- [ ] Update README, status, decisions, and phase evidence.
- [ ] Request an independent audit; resolve findings.
- [ ] Submit a pull request to main and request owner review.
- [ ] Record owner acceptance before phase 02.
