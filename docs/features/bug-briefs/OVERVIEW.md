# Bug Briefs

## Purpose

Help developers and QA capture and prepare clear software issue reports with optional local AI assistance.

## Proposed user flow

A user opens the dashboard, creates or edits a brief, adds text or evidence, reviews suggested content, and saves or exports a report. The first approved slice and its acceptance criteria must be defined during phase planning.

## Product boundaries

- Bug Briefs is a feature area in AI Local Tools, not a separate application.
- Local AI is optional per task and must not block basic editing or local saving.
- Reports and AI output require user review.
- No ticket-system integration or backend is approved by this package.

## Status

Planned. No dashboard, editor, model, or storage implementation is included in this archive. See [selected requirements](REQUIREMENTS.md) and [project status](../../STATUS.md).
