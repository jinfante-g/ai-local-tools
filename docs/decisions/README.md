# Decision records

Use an Architecture Decision Record for a material choice affecting architecture, security, privacy, dependency selection, data handling, model/runtime selection, or phase scope.

- Copy [ADR_TEMPLATE.md](ADR_TEMPLATE.md).
- Number records sequentially: ADR-0001-short-title.md.
- Keep superseded records and link the replacing decision.
- Record evidence and reviewer for compatibility, license, and policy checks.
- A proposal is not a decision until its status and owner approval are recorded.
