# Documentation rules

- Write project documentation in English; write Slack progress updates in Spanish.
- Mark statements as confirmed, proposed, pending, planned, or implemented when the distinction matters.
- Never report a planned feature as implemented.
- Keep docs/STATUS.md current when a phase or open check changes.
- Store durable decisions in ADRs and phase proof in evidence records.
- Use Markdown and screenshots for evidence; redact sensitive information and use synthetic examples.
- Link to the source document rather than copying long sections into multiple files.
- Keep rules short, actionable, and consistent with corporate standards.
