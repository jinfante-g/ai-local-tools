# Evidence records

Keep reviewable evidence for each phase under a phase-specific folder, for example docs/evidence/phase-01/.

Use the [phase evidence template](../templates/PHASE_EVIDENCE.md). Include Markdown summaries and screenshots when useful.

- Use synthetic or explicitly approved data.
- Redact sensitive information from screenshots and logs.
- Record exact commands/checks and actual outcomes.
- Identify model/runtime versions and device/browser for AI evidence.
- Link pull requests, audit records, decisions, and acceptance.
- Do not store large model files or user issue data in the repository.
